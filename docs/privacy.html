Política de Privacidade – Livelo Auto

Última atualização: 21 de novembro de 2026

O Livelo Auto é uma extensão para Chrome e Edge que ativa o link de pontos da Livelo quando você entra em lojas parceiras. Este documento explica quais dados a extensão trata, para que serve e onde ficam armazenados.

Este projeto é independente e não é afiliado, patrocinado ou mantido pela Livelo.

1. Resumo

  • Não há servidor próprio do desenvolvedor. A extensão não envia dados para o autor nem para terceiros de análise (sem analytics, sem anúncios, sem rastreadores).
  • Os dados ficam no seu navegador, em chrome.storage.
  • O único envio de dados é para a API da própria Livelo (apis.pontoslivelo.com.br) e para o site livelo.com.br, quando necessário para gerar o link de pontos.
  • Não vendemos nem compartilhamos dados com terceiros.

2. Dados que a extensão trata

  • CPF: informado por você no popup. É usado para pedir à Livelo o link personalizado de algumas lojas (por exemplo, Mercado Livre). É salvo localmente e enviado somente à API da Livelo, no momento de gerar o link.
  • Endereços (URLs) das páginas que você visita: a extensão observa a navegação principal para saber se a loja atual é parceira da Livelo. Essa verificação é feita localmente, com a lista de parceiros. Nenhum histórico de navegação é guardado nem enviado.
  • Cookies do site da Livelo: a extensão verifica apenas se existe o cookie de sessão de login (nome KEYCLOAK_IDENTITY), para mostrar se você está logado. O valor do cookie não é lido para uso nem enviado a lugar nenhum.
  • Preferências e cache: modo de exibição (automático ou banner), lojas desativadas, links gerados, catálogo de parceiros, contadores de diagnóstico e o identificador de pixel de rastreio da Livelo (gtm_ga_ids), copiado do armazenamento local do site da Livelo para montar o link.

3. Como os dados são usados

  • Montar o link de pontos da loja que você está visitando.
  • Mostrar o banner de ativação e o status no popup.
  • Controlar os intervalos entre requisições à Livelo, para evitar bloqueio do seu IP pelo serviço.

4. Armazenamento e retenção

Todos os dados ficam no seu navegador (chrome.storage.local e chrome.storage.session). Os links gerados, que incluem o CPF no cache, permanecem até serem substituídos ou até você remover a extensão. Para apagar seu CPF, limpe o campo no popup e remova a extensão para apagar o restante.

5. Compartilhamento

Não compartilhamos dados com terceiros. Os únicos destinos de rede são a API da Livelo (apis.pontoslivelo.com.br) e o site livelo.com.br, ambos controlados pela Livelo, conforme a política de privacidade da Livelo.

6. Permissões usadas

  • storage / alarms: guardar preferências e cache localmente e agendar atualizações do catálogo de parceiros.
  • webNavigation / webRequest: detectar a loja que você está visitando e ativar o link no momento certo. Não bloqueia nem altera requisições.
  • scripting: exibir o banner de ativação na página da loja parceira.
  • cookies: verificar se você está logado na Livelo (somente o nome do cookie de sessão).
  • Acesso a todos os sites (https://*/*): necessário porque as lojas parceiras são muitas e mudam; a extensão só age quando a loja está no catálogo da Livelo.

7. Seus direitos

Você pode, a qualquer momento, apagar o CPF pelo popup, desativar a extensão ou removê-la do navegador, o que apaga os dados armazenados localmente. Como os dados não estão em servidores do desenvolvedor, não há cópias a solicitar. Para dúvidas sobre dados mantidos pela própria Livelo, consulte a política de privacidade da Livelo.

8. Crianças

A extensão não se destina a menores de 18 anos e não coleta conscientemente dados de crianças.

9. Alterações

Se esta política mudar, a nova versão será publicada nesta página com a data de atualização.
